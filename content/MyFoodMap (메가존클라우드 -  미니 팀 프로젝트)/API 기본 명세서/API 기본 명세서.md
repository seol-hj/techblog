## **😎**소개

> 개인 스페이스에 추가하셔서 자유롭게 커스텀 하시면 됩니다!

1. 😒 프로젝트마다 API 명세서 작성하기 귀찮으신 분들!
2. 😣 이번이 프로젝트는 첨이라 어떻게 작성할지 모르겠다 하시는 분!
3. 😥 설계 미팅 준비하는데 어떻게 구성할지 막연하신 분들을 위해 🔥**노션 API 명세서 템플릿(무료)**를 공개합니다!

### **🧠 이거 왜써요?**

4. 🗂️ 도메인(카테고리)별로 모아서 관리 가능
5. 🔖 표 or 카테고리 형식 둘 다 지원
6. 👓 상세 페이지에 `request`, `params`, `response`, `example`, `status`까지 기록 가능
7. 💫 자유롭게 커스텀 가능
8. ⏱️ “+ 추가하기” 한 번이면 새로운 API도 바로 등록 가능!
