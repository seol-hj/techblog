## 2. 줄바꿈 & 문단

마크다운은 기본적으로 **엔터 한 번은 줄바꿈 X**

```
첫 줄  
둘째 줄
```

또는 `<br>` 사용

```
첫 줄<br>  
둘째 줄
```

## 4. 목록 (List)

### 순서 없는 목록

```
- 항목1  
- 항목2  
	- 하위항목
```

- 항목1
- 항목2
    - 하위항목

### 순서 있는 목록

```
1. 첫번째  
2. 두번째
```

## 11. Callout

```
> [!타입]
> 내용
```

- `>` 필수

- Callout 종류
	- ```
	  > [!info]
	  > 일반 정보 설명
	  ```
	  
	- ```
	  > [!tip]
	  > 팁이나 노하우
	  ```

	- ```
	  > [!warning]
	  > 주의해야 할 내용
	  ```

	- ```
	  > [!danger]
	  > 위험하거나 치명적인 부분
	  ```

	- ```
	  > [!note]
	  > 정리 메모
	  ```
