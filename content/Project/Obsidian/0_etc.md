# 1. SaaS 기반 플랫폼
---
## ✍️ 1. Medium

### 특징
- 가입하면 바로 글 작성 가능
- 디자인 신경 쓸 필요 없음
- SEO/트래픽 일부 자동 확보

### 장점
- 진입장벽 낮음
- 해외 독자 접근성 좋음
- UI 세련됨

### 단점
- 커스터마이징 거의 불가
- 내 도메인 브랜딩 약함
- 정책 변경 리스크
---
## 👨‍💻 2. Dev.to

### 특징
- 개발자 커뮤니티 중심
- 코드 작성에 최적화

### 장점
- 개발자 대상 노출 좋음
- 태그 기반 확산 강함
- 오픈소스 친화적

### 단점
- 브랜딩 거의 불가
- 개인 자산 느낌 약함

---
## 📰 3. WordPress
### 특징
- CMS의 대표 주자
- 테마/플러그인 생태계 매우 큼

### 장점
- 커스터마이징 강력
- SEO 플러그인 다양
- 쇼핑몰/회원 기능 확장 가능

### 단점
- 서버 관리 필요 (자체 호스팅 시)
- 보안 관리 부담
- 플러그인 충돌 이슈

---
## 📝 4. Tistory
### 특징
- 카카오에서 운영하는 국내 대표 블로그 플랫폼
- HTML/CSS 직접 수정 가능
- 광고 및 수익화 구조 지원

### 장점
- 커스터마이징 자유도 높음
- 애드센스 수익화 가능
- 국내 SEO 유리
- 스킨(테마) 다양

### 단점
- 플랫폼 정책 영향 받음
- 광고 삽입 이슈 발생 가능
- 완전한 소유 개념은 아님

---
## ✍️ 5. Velog
### 특징
- 개발자 전용 블로그 플랫폼
- Markdown 기반 에디터
- GitHub 로그인 연동

### 장점
- 개발자 커뮤니티 중심 노출
- 코드 작성 최적화
- UI 깔끔
- 글 작성 진입장벽 낮음

### 단점
- 디자인 커스터마이징 거의 불가
- 개인 브랜딩 약함
- 플랫폼 종속

---

# 2. 정적 사이트 기반
---
## 🌐 6. GitHub Pages
### 특징
- GitHub 저장소 → 자동 배포
- 무료 정적 호스팅

### 장점
- 비용 0원
- Git 기반 관리
- 커스텀 도메인 가능

### 단점
- 동적 기능 불가
- 빌드 설정 필요
- 디자인 직접 구성해야 함

---
## ⚡ 7.  Hugo
### 특징
- Go 기반 정적 사이트 생성기
- 매우 빠른 빌드 속도

### 장점
- 성능 뛰어남
- SEO 좋음
- 테마 다양

### 단점
- 초기 세팅 난이도 있음
- CLI 기반

---
## 🪨 8. Obsidian
### 특징
- Markdown 작성 도구 + 정적 사이트 생성기 조합
- 옵시디언 링크(`[[링크]]`) 자동 변환
- Graph View 웹에서 지원
- 로컬 기반 지식 시스템을 그대로 블로그화

### 장점
- 플랫폼 종속 없음
- Git 기반 관리
- 인프라 구조 학습 가능
- 지식 연결 구조 유지

### 단점
- 초기 세팅 필요
- 프론트 구조 이해 필요

---
```
- Medium 👉 글 쓰는 것에만 집중하고 싶을 때 좋음
- Dev.to 👉 해외 개발자 대상 글 공유용
- WordPress 👉 상업용 블로그 / 브랜드 사이트에 적합
- Tistory 👉 커스터마이징 가능한 SaaS
- Velog 👉 전형적인 SaaS 블로그 플랫폼
- GitHub Pages 👉 포트폴리오 + 기술 블로그 조합에 좋음
- Hugo 👉 개발자다운 블로그를 만들고 싶을 때
- Obsidian 👉 로컬 기반으로 지식을 구조화해 관리하고 확장하고 싶을 때
```
