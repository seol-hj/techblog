## 1. 데이터베이스 분류 개요

데이터베이스는 **데이터 구조 + 접근 방식 + 확장 방법**에 따라 분류한다.

> 실무에서는 보통 다음 3단계로 사고한다
> **① 데이터 구조 → ② 트랜잭션 요구 → ③ 확장/운영 방식**

---

## 2. 관계형 데이터베이스 (RDBMS)

![](Experience/MGC_SA_Bootcamp/3_데이터베이스/img/20260212.png)
![](Experience/MGC_SA_Bootcamp/3_데이터베이스/img/20260212-1.png)

### 2.1 개념

- **행(Row)과 열(Column)** 기반의 정형 데이터
- **테이블 간 관계(Relationship)** 를 명확히 정의
- **SQL** 사용

### 2.2 핵심 특징

- 스키마 고정 (Schema-on-write)
- ACID 트랜잭션 보장
- JOIN 가능
- 데이터 무결성 매우 강함

### 2.3 대표 DB

- MySQL
- PostgreSQL
- Oracle Database
- MariaDB

### 2.4 언제 사용?

- 금융, 결제, 주문, 회원 관리
- 데이터 정합성이 가장 중요한 시스템

## 3. NoSQL 데이터베이스 (비관계형 DB)

![](Experience/MGC_SA_Bootcamp/3_데이터베이스/img/20260212-2.png)
![](Experience/MGC_SA_Bootcamp/3_데이터베이스/img/20260212-3.png)

### 3.1 개념

- **관계보다는 확장성과 유연성** 중심
- JOIN 없음 또는 제한적
- 대규모 분산 환경에 최적화

### 3.2 공통 특징

- Schema-less 또는 Schema-on-read
- 수평 확장(Scale-out) 쉬움
- ACID 대신 **BASE** 모델 채택

## 5. 인메모리 데이터베이스 (In-Memory DB)

![](Experience/MGC_SA_Bootcamp/3_데이터베이스/img/20260212-10.png)

- 디스크가 아닌 **RAM 기반**

### 대표

- Memcached

### 사용

- 캐시 계층
- DB 부하 감소용

## 7. 데이터베이스 선택 기준

|기준|선택 방향|
|---|---|
|트랜잭션 중요|RDB|
|스키마 유연|Document DB|
|초고속 조회|Key-Value|
|대규모 분산|NoSQL|
|관계 탐색|Graph|
|운영 최소화|Managed DB|
