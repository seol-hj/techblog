### Amazon EC2란?

**Amazon EC2 (Elastic Compute Cloud)** 는

👉 **클라우드에서 컴퓨팅 자원(서버)을 필요할 때 빌려 쓰는 서비스**

- 물리 서버를 직접 구매/설치할 필요 없음
- 몇 분 안에 서버 생성 가능
- 필요하면 늘리고, 필요 없으면 줄이거나 종료 가능

> 💡 한 줄 요약
> 
> **EC2 = 클라우드에서 서버를 빌려 쓰는 AWS의 핵심 컴퓨팅 서비스**

---

### 클라우드 컴퓨팅 개념

### 클라우드 = 빌려 쓰기

- 서버, 스토리지, 네트워크를 **필요한 만큼만 사용**
- 사용한 만큼만 비용 지불 (**Pay-as-you-go**)

### 클라우드 컴퓨팅 = 컴퓨팅 자원 빌려 쓰기

- CPU, 메모리, 디스크, 네트워크를 조합해 서버 구성
- EC2가 이 역할을 담당

---

### EC2의 핵심 특징

### 1. 컴퓨팅을 빌려 쓰는 서비스

- 웹 서버, DB 서버, 백엔드 서버 등 **서버가 필요한 모든 경우에 사용**
- 물리 서버와 동일한 개념이지만 관리 부담 없음

---

## Amazon EC2의 장점

### 1️⃣ 초 단위 온디맨드 가격 모델

- **초 단위 과금**
- 선결제 / 장기 약정 필요 없음
- 필요할 때 켜고, 안 쓰면 끄면 됨

> 💡 실무 포인트
> 
> 테스트 서버, 단기 프로젝트에 매우 유리

---

### 2️⃣ 빠른 구축 속도와 확장성

- 몇 분 내 전 세계에 서버 수백 대 생성 가능
- 트래픽 증가 시 빠르게 서버 확장 가능

---

### 3️⃣ 다양한 구성 방법 지원

- 용도별 최적화된 서버 구성 가능
    - 머신러닝
    - 웹 서버
    - 게임 서버
    - 이미지/데이터 처리
- **다양한 인스턴스 타입 + 과금 모델 선택 가능**

---

### 4️⃣ 여러 AWS 서비스와 연동

- **Auto Scaling**: 트래픽에 따라 서버 자동 증감
- **ELB (Elastic Load Balancer)**: 트래픽 분산
- **CloudWatch**: 모니터링 및 알람

> 💡 EC2 단독으로 쓰기보다
> 
> **다른 AWS 서비스와 조합해서 사용하는 게 핵심**

---

## Amazon EC2 사용 사례

- 데이터베이스 서버
- 웹 서버
- 머신러닝 학습 서버
- 애플리케이션 백엔드 서버
- 데이터 처리 작업
- 기타 서버가 필요한 모든 작업

---

## 이번 챕터에서 배우는 내용 (전체 흐름)

- EC2 개념과 기본 사용법
- EC2와 함께 쓰는 주변 AWS 서비스
- 고급 AWS 서비스와의 연계 필요성
    - 예: **ALB SSL Termination**
        - 인증서 구매 없이 HTTPS 구현
    - **Route 53**: DNS 서비스
    - **ACM**: 인증서 관리 서비스
